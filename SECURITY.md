# Política de segurança

Não publique tokens, segredos, chaves, dados pessoais ou institucionais em issues e PRs públicos. Se encontrar dados sensíveis, reporte privadamente ao mantenedor e revogue quaisquer credenciais afetadas.

Uma skill pública não deve exigir acesso indevido, contornar permissões, nem assumir que existe autorização para executar operações destrutivas. Todas as dependências e licenças devem ser auditadas antes de uma publicação.
