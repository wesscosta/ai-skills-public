# Contribuição

Este repositório distribui **somente skills homologadas**. A fonte de desenvolvimento é privada. Propostas e relatórios de problemas podem ser enviados por issues, sem credenciais ou dados pessoais.

Uma skill deve conter `SKILL.md` com frontmatter válido, gatilhos precisos, limitações, casos de teste e arquivos com licença compatível. A publicação exige revisão humana de todos os arquivos, dependências e dados sensíveis.
