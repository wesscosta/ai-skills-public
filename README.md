# AI Skills — Public

Coleção pública de skills para agentes de IA, com publicação seletiva e revisão de segurança.

> **Nenhuma skill foi aprovada para publicação até o momento.**

## Organização

Cada skill aprovada aparecerá em `skills/<nome>/SKILL.md`, com recursos auxiliares opcionais, no formato [Agent Skills](https://agentskills.io/specification).

## Distribuição e qualidade

O desenvolvimento ocorre no repositório **privado**. Esta versão pública recebe somente skills explicitamente aprovadas, após auditoria de instruções, testes, licenças, dependências e privacidade. A existência de um `SKILL.md` não comprova compatibilidade universal nem homologação de comportamento.

Leia [CONTRIBUTING.md](CONTRIBUTING.md) e [SECURITY.md](SECURITY.md).
